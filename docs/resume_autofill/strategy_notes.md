# 简历自动投递动作策略

## 1. 动作分类

后续分析每个站点时，统一按下面几类动作记录：

1. `direct_fill`
   - 直接找到输入框并写值
2. `select_option`
   - 先展开下拉，再命中选项
3. `pick_date`
   - 原生日期框或站点自定义日期控件
4. `click_add_then_fill`
   - 先点“添加经历 / 新增项目 / 添加教育”，再填新出现的表单
5. `expand_then_fill`
   - 先展开折叠区、弹窗或详情面板
6. `multi_step_group`
   - 同一段经历需要跨多个块填写

## 2. 字段优先级

优先做最值得自动化的字段：

- 基本信息
- 求职期望
- 教育经历
- 实习经历
- 项目经历
- 自我介绍

## 3. 站点策略落地要求

- 先保证幂等：重复执行不能把页面越点越乱
- 先保证可回退：站点策略失败时，仍保留通用填表
- 先保证可观测：扩展侧要能回报“命中了哪个策略、填了几项、哪些动作待补”

## 4. 截图分析模板

每次收图或录屏后，至少回答下面几个问题：

- 这个字段是直接输入、下拉、日期，还是先点添加按钮？
- 一个经历块是默认存在，还是动态新增？
- 标签文本和真实字段语义是否一致？
- 页面是否用了自定义组件，导致原生 `input/select` 不够用？
- 哪些字段可以稳定自动填，哪些字段需要人工复核？

## 5. Bilibili 首张截图提炼出的补充规则

- 遇到 `教育经历 / 实习经历 / 项目经历` 这类带编号块的页面，不要把它们当成单字段区；默认按“列表型经历组”处理
- 遇到 `起止时间 + 至今复选框` 组合时，时间策略要允许：
  - 起始时间写入
  - 结束时间写入
  - 或结束时间留空并勾选 `至今`
- 遇到 `手机号` 这类复合字段时，要拆成：
  - 区号/地区选择
  - 主号码输入
- 出现上传区时，第一阶段默认跳过，不要让上传动作阻塞文本型字段填充

## 6. Bilibili 第二批截图提炼出的补充规则

- `出生日期` 与 `经历起止时间` 必须分成两类控件：
  - `出生日期` -> 日历型 `pick_date`
  - `经历时间` -> 年月型 `pick_month_range`
- 若下拉面板已展开并且选项文本可见，优先按可见文本点击，不优先做模糊写值
- 遇到 `添加教育经历 / 添加实习/工作经历 / 添加项目经历` 这类新增入口时：
  - 先比较现有块数量与待填记录数量
  - 只在不足时点击新增
  - 每点击一次后重新查询块列表
- `项目经历` 不应被拖到后续版本；若页面已包含项目名称、角色、描述、链接等主字段，项目组策略应与教育/实习同级进入首版

## 7. 蚂蚁集团截图提炼出的补充规则

- 若页面把 `个人信息` 与 `教育经历` 同时做成细粒度教育背景表单，不要假设两者字段完全一致；应允许：
  - 顶部基础个人资料一套映射
  - 教育块内部再有一套更细字段映射
- 遇到 `手机号` 这类左侧国家码/区号、右侧主号的控件，默认归入 `multi_field_group`
- 遇到 `国家/地区`、`是否英语授课学校专业`、`双学位`、`你是如何获悉本次` 这类字段时，优先假设为可见文本下拉，而不是普通输入框
- 若页面出现 `技术开发语言` 这类标签式能力录入区，不要先按普通单行输入处理；应先判断是否为：
  - 标签输入
  - 候选项点击
  - 多选 chips
- 蚂蚁集团页的教育字段明显比当前本地默认结构更细，后续若要提高填充率，需逐步补本地字段：
  - `country_region`
  - `education_city`
  - `personal_gpa`
  - `advisor`
  - `research_direction`
  - `english_taught_major`

## 8. 携程截图提炼出的补充规则

- 携程简历页更像“站内简历维护页”，不是一次性提交表单；策略上要允许：
  - `profile_sync`
  - `group_fill`
  - 分组幂等重填
- 携程教育/实习/获奖当前截图更像完整日期控件，格式为 `YYYY-MM-DD`：
  - 优先走 `pick_date`
  - 不直接复用 Bilibili 的 `pick_month_range`
- 携程教育块比当前默认结构更细，已确认包含：
  - `college`
  - `gpa`
  - `rank`
  - `second_major`
  - `research_direction`
  - `advisor`
- 针对携程教育块，本地资料侧应优先准备这些细字段：
  - `education_gpa`
  - `education_rank`
  - `second_major`
  - `research_direction`
  - `advisor`
- 携程项目块当前截图里只明确确认：
  - `项目名称`
  - `项目职责`
  因此第一版不要假设一定存在 `项目链接`、`完整项目描述`、`项目时间`
- 携程获奖块可以优先按列表型最小映射处理：
  - `award_time`
  - `award_name`
