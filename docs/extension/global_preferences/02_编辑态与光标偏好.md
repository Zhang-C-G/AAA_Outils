# 全局私人偏好：编辑态与光标偏好
最近同步：`2026-04-25`

## 1. 定位

本文件记录进入编辑态时的通用偏好。

## 2. 具体规则

### 2.1 原位编辑优先

- 如果某结构支持直接改名、直接编辑，优先采用原位编辑
- 不优先使用“点一下后整个控件突然换形态”的实现

### 2.2 尺寸稳定优先

- 进入编辑态、切换态、展开态时，优先保持区域尺寸稳定
- 不喜欢明显的外框突变、尺寸突变、控件替换感

### 2.3 编辑态不默认全选

- 进入重命名或编辑态时，不默认把整段内容全选
- 优先采用“直接聚焦，光标放在文本末尾”的方式

说明：

- 默认全选虽然方便覆盖输入，但也容易导致误删
- 对标题、栏目名这类短文本，当前更偏好在原内容基础上继续微调

### 2.4 长文本编辑必须保留段落与换行

- 对 `textarea` 一类长文本输入，换行、分段、空行属于正文结构的一部分，不能在保存时被压平成一个大段落
- 像 Prompt、个人基本信息、说明文本、长备注这类内容，保存后再次打开时必须保持原有段落结构
- 不允许出现“编辑时有换行，保存后被自动替换为空格”的行为
- 若底层存储格式本身不支持原样多行，也必须增加转义/编码层来保留换行语义，而不是牺牲编辑体验


### 2.5 固定编辑框允许内部滚动

- 对表格中的长文本值输入，如果该区块承担稳定扫视职责，优先固定输入框高度，不跟随内容无限长高
- 文本超出固定高度时，允许在输入框内部上下滚动查看和编辑
- 这类“固定框体 + 内部滚动”优先用于字段名已稳定、用户主要是在值区持续维护内容的界面
