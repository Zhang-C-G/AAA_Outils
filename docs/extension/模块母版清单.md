# 模块母版清单

最近同步：`2026-05-09`

## 1. 文档定位

这份文档用于列出“当前已经值得复用的模块母版”。  
它不是实现代码清单，而是复用清单。

每个母版至少说明：

- 适用场景
- 核心结构
- 默认继承哪些偏好
- 不适合拿来做什么

## 2. 当前母版

### 2.1 列表 + 目录 + 正文工作区母版

- 来源模块：`B 笔记`、`C 笔记显示`
- 正式模板文档：
  - `docs/templates/LIST_OUTLINE_BODY_WORKSPACE_TEMPLATE.md`
- 适用场景：
  - 左侧需要多条内容列表
  - 中间需要结构目录
  - 右侧需要稳定正文工作区
  - 目录需要服务正文，不是独立列表
- 核心结构：
  - 左列内容列表
  - 中列结构目录
  - 右列正文工作区
  - 顶部视图切换
  - 同构列头与内容框
- 默认继承：
  - `13_列表排序偏好.md`
  - `16_结构目录偏好.md`
  - `17_笔记类目录与正文工作区偏好.md`
  - `04_自动保存与保存按钮偏好.md`
- 不适合：
  - 纯配置表
  - 纯表单录入页
  - 没有目录层级的数据维护场景

### 2.2 筛选器 + 表格母版

- 来源模块：`F 简历自动填写 / 公司投递面板`、`I API 管理中心`
- 适用场景：
  - 多字段维护表
  - 多状态、多类型、多规模筛选
  - 用户需要回看历史项
- 核心结构：
  - 顶部轻量筛选区
  - 中部表格主体
  - 底部行级操作区
- 默认继承：
  - `18_表格与筛选器偏好.md`
- 不适合：
  - 只有极少量字段和极少量行的小表
  - 没有持续维护需求的一次性展示表

### 2.3 筛选器 + 分页 + 表格母版

- 来源模块：`F 公司投递表` 的后续目标形态
- 适用场景：
  - 表格行数持续增长
  - 单屏无法稳定扫视
  - 筛选后仍然会有较多结果
- 核心结构：
  - 顶部筛选器
  - 中部表格
  - 底部分页区
  - 状态持久化
- 默认继承：
  - `18_表格与筛选器偏好.md`
  - `00_通用偏好结论.md` 中关于视图状态恢复的规则
- 不适合：
  - 结果数量长期很少的轻量列表

### 2.4 自动保存表单母版

- 来源模块：`F 简历字段维护`、`E 个性化设置`
- 适用场景：
  - 字段编辑频繁
  - 用户不喜欢显式保存按钮
  - 修改后应立即生效或立即落盘
- 核心结构：
  - 输入即更新内存态
  - 短延迟自动保存
  - 刷新与重进恢复
- 默认继承：
  - `04_自动保存与保存按钮偏好.md`
  - `00_通用偏好结论.md` 中自动保存相关规则
- 不适合：
  - 高风险不可逆批量操作
  - 必须二次确认才能生效的操作

### 2.5 说明条 / 入口条母版

- 来源模块：`E 截图问答`、`F 简历自动填写`
- 适用场景：
  - 需要在页面头部提示当前入口或当前状态
  - 需要用轻量说明承接跨视图切换
- 核心结构：
  - 单行提示
  - 可点击入口
  - 低对比斜杠纹理背景
- 默认继承：
  - `15_说明条偏好.md`
- 不适合：
  - 长说明文档
  - 多步骤配置向导

### 2.6 悬浮窗设置面板母版

- 来源模块：`E 截图问答`
- 适用场景：
  - 有主题色、透明度、增强模式、设备选择等悬浮窗设置
  - 设置项变更后需要即时生效
- 核心结构：
  - 基础设置 / 高级设置分层
  - 开关、色轮、透明度档位
  - 自动保存
- 默认继承：
  - `00_通用偏好结论.md`
  - `11_按钮偏好.md`
  - `15_说明条偏好.md`
- 不适合：
  - 纯只读信息页

## 3. 使用规则

后续模块引用母版时，必须在对应模块文档里写明：

1. 采用了哪个母版
2. 保留了哪些原规则
3. 做了哪些例外
4. 为什么这些例外成立

## 4. 后续扩展原则

只有当某种结构已经在多个模块中稳定复用，才允许升格为新的母版。  
不要把一次性的局部写法过早升格成模块库。
