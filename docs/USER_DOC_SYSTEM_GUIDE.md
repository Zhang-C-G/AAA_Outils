# 用户文档系统使用说明

最近同步：`2026-05-14`
状态：`active`

## 1. 文档简称表

- `总指挥`：总指挥文档
- `交接状态`：项目当前状态
- `项目总览`：项目总览
- `文档总图`：文档分层总图
- `检查点规则`：git / checkpoint 规则
- `改动流水`：本轮改动流水
- `收尾清单`：收尾检查清单
- `动作记录`：全局动作记录
- `文档变更`：文档改动记录
- `模块主文档`：目标模块主文档
- `模块过程文档`：目标模块修改过程文档
