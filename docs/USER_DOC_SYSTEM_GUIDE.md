# 用户文档系统使用说明

最近同步：`2026-05-14`
状态：`active`

## 1. 文档简称表

- `总指挥`：总指挥文档
- `交接状态`：项目当前状态
- `项目总览`：项目总览
- `文档总图`：文档分层总图
- `检查点规则`：git / checkpoint 规则
- `改动流水`：本轮改动流水
- `收尾清单`：收尾检查清单
- `动作记录`：全局动作记录
- `文档变更`：文档改动记录
- `模块主文档`：目标模块主文档
- `模块过程文档`：目标模块修改过程文档

## 2. 命令进入后的总判断树

先用这 5 步：

1. 先看这是不是实际任务
2. 再看有没有命中具体模块
3. 再给任务分类
4. 一旦已判断出阶段，就走对应阶段通用规则
5. 最后补文档、测试、git / checkpoint 收尾
