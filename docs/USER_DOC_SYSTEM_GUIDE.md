# 用户文档系统使用说明

最近同步：`2026-05-14`
状态：`active`

## 1. 文档简称表

- `总指挥`：总指挥文档
- `交接状态`：项目当前状态
- `项目总览`：项目总览
- `文档总图`：文档分层总图
- `检查点规则`：git / checkpoint 规则
- `改动流水`：本轮改动流水
- `收尾清单`：收尾检查清单
- `动作记录`：全局动作记录
- `文档变更`：文档改动记录
- `模块主文档`：目标模块主文档
- `模块过程文档`：目标模块修改过程文档

## 2. 命令进入后的总判断树

```text
一个命令进入

|   |
|   +-- 是
|   |   |
|   |   +-- 交接状态

|   |
|   +-- 否

+-- 这是实际任务吗？

|   +-- 是
|   |   |

|   |   |   |

|   |   |   +-- 重点：显性回答、状态显示、文档同步、检查点规则
|   |   |
|   |   +-- 是否命中具体模块？

|   |       |   |   |   +-- 如结构已稳定，再判断能否进入第二阶段

|   |       |   |   |   +-- 先看这次是补结构，还是补真实闭环

|   |       |   |   |       +-- 偏第二阶段
|   |       |   |   |
|   |       |   |   +-- bug 修复

|   |       |   |   |   +-- 结构层 bug：偏第一阶段
|   |       |   |   |   +-- 保存 / 持久化 / 运行时 bug：偏第二阶段

|   |       |   |   +-- 回归修复

|   |       |   |   |

|   |       |   |       +-- 还要进入：行为闭环 / 持久化 / 运行时偏好

|   |       |   +-- 是否涉及特殊链路？

|   |       |           +-- 模块过程文档
|   |       |           +-- 交接状态

|   |           |   |

|   |           |

|   |           |   |
|   |           |   +-- 是
|   |           |   |   +-- 文档总图
```
