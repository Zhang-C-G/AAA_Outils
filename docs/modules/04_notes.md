# 模块 04：B 笔记

最近同步：`2026-05-24`

## 模块目标

- 管理多条笔记（新建、编辑、删除）。
- 输入过程中自动保存当前编辑内容。
- 支持 Markdown 内容写入，并稳定落盘到本地笔记文件。

## 核心主功能

- 核心是笔记内容可编辑、可保存、可自动保存，且刷新后不丢。
- 任何界面调整或次级交互问题，都不能以牺牲自动保存链路为代价。
- “笔记显示”是独立模块，不属于本模块；两者现在也不共享同一套笔记文件。

## 当前状态

- 当前状态：`第一阶段主体已稳定，第二阶段局部能力已落地`
- 已稳定的主链包括：笔记新建、编辑、删除、拖拽排序、自动保存、结构目录、提取编辑。
- 已落地的第二阶段局部能力包括：`最终版本` 直接编辑、选区着色、列表项退回普通正文、导出当前笔记、正文头部双行工作带、`最终版本 -> Markdown` 文本锚点定位、切换笔记防串写、图片资源文件化落盘。
- 后续继续扩展时，仍必须先保护“正文内容不丢 + 自动保存不退化 + 导出内容与当前正文一致”这三条主链。

## 当前默认交互

- 标题或正文输入后，前端延迟自动保存。
- 切换笔记、切换模块、刷新前草稿恢复，仍然作为自动保存链路的兜底。
- 正文失焦时会补一次静默保存；`最终版本` 下的选区改色、列表格式退出等结构性编辑也会立即进入静默保存。
- 正文切到“最终版本”后，允许直接编辑正文，并支持选中文字后通过小型悬浮工具条追加文字色或背景色。
- 在 `最终版本` 中，如果光标位于列表项开头，按 `Backspace / Delete` 会把该行从列表项退回普通正文。
- 正文头部改为上下两行：第一行左侧显示保存状态点与字数，右侧显示小搜索框与手动保存按钮；第二行放导出与 `Markdown / 最终版本` 切换。
- 当前允许保留一个手动“保存”按钮，但它只作为主动触发现有保存链路的补充入口，不替代自动保存。
- 无论自动保存、手动保存还是导出前保存，只要当前停在 `最终版本`，都会先把当前正文 DOM 强制同步回 Markdown 源码，再进入保存链路。
- 正文搜索框已接入轻量搜索：按 `Enter` 跳到下一个匹配位置，按 `Shift + Enter` 反向跳转。
- 支持导出当前笔记，并可选择 `Markdown / HTML / PDF / TXT / JSON` 格式。
- 导出前会先同步 `最终版本` 的最新正文并静默保存；提取视图下不允许直接导出当前笔记。
- `PDF` 当前通过本地后端调用浏览器无头导出，直接下载真实 `.pdf` 文件，不再额外弹打印窗口。
- 从 `最终版本` 切到 `Markdown` 时，优先按当前视窗第一块可见正文的文本锚点定位；标题锚点与滚动比例仅作为兜底。
- 在 `最终版本` 中粘贴或拖入的 base64 图片，不再原样塞进 `notes/*.md`，而是由后端改写为 `/note-assets/<note-id>/...` 资源文件引用。
- 当前笔记加载结果会携带 `updatedAt`，前端会记录最近一次已加载版本与最近一次已保存版本，用于刷新恢复与保存后状态校准。

## 切换笔记竞态修复（2026-05-22）

- 问题：快速连点切换时，旧保存可能把 A 笔记正文写到 B 笔记文件。
- 策略：
  1. `selectNote` 串行队列，禁止并发切换。
  2. 切换瞬间先**快照**当前编辑器内容（含笔记 ID），再按该快照保存离开中的笔记。
  3. `loadNoteContent` 带世代号，过期加载结果直接丢弃。
  4. `saveNotePayload` 仅在「保存版本号未变且仍是当前笔记」时清除 dirty。

## 图片资源文件化（2026-05-24）

- 问题：`最终版本` 里如果直接粘贴 data URL 图片，原始 base64 文本会让笔记文件膨胀，且不利于后续导出与恢复。
- 策略：
  1. 保存时先扫描 Markdown 中的内嵌 `data:image/...;base64,...` 图片。
  2. 后端按内容哈希写入 `webui/config/note-assets/<note-id>/`。
  3. 正文中的图片链接统一改写为 `/note-assets/<note-id>/<sha>.<ext>`。
  4. 保存成功后，前端以服务端回写后的标准正文为准，保证当前编辑器、落盘文件与导出源一致。

## 改动后必查

1. 新建笔记后可保存并刷新可见。
2. 输入标题或正文后，不点任何保存按钮也能自动落盘。
3. 删除确认流程正常且落盘生效。
4. Markdown 内容可正常保存到 `notes/*.md`。
5. 刷新页面或重启后，笔记编辑内容不丢失。
6. 切换到其他笔记前，当前未落盘内容会先自动保存。
7. 当前笔记标题修改后，左侧列表标题能同步刷新。
8. “最终版本”里的选区文字色 / 背景色修改后，切回 Markdown、刷新页面、重新打开笔记都不能丢。
9. 导出当前笔记时，导出文件内容应与当前最新正文一致，且 `Markdown / HTML / PDF / TXT / JSON` 格式选择生效。
10. 从 `最终版本` 切回 `Markdown` 时，正文应优先落到当前可见正文附近，而不是明显跳偏。
11. 目录长标题下，`H1 / H2 / H3` 层级标签必须持续可见，不被标题文字挤掉。
12. 正文头部双行排布应保持稳定：第一行状态在左、搜索与保存在右，第二行承载导出与视图切换。
13. 快速切换两条笔记后，各自文件内容不得互换或串写。
14. 在 `最终版本` 中粘贴图片后，`notes/*.md` 内应保存为 `/note-assets/...` 引用，而不是长段 base64。
15. 刷新页面后，若刚完成保存，前端 dirty 状态与已加载版本戳应保持一致，不重复误报未保存。
