# B模块第一阶段：重型私人笔记重构

最近同步：`2026-04-28`  
状态：`stage1`

## 1. 文档定位

- 本文档只负责 B 模块第一阶段：界面、结构、入口、占位与边界定义
- 本文档不负责第二阶段的完整 Markdown 分块持久化、关键词索引与全文检索闭环

## 2. 输入文档

- 总规则：`docs/AI_HANDOFF.md`
- 开发总指引：`docs/extension/AI_DEVELOPMENT_PLAYBOOK.md`
- 全局偏好总入口：`docs/extension/全局私人偏好文档.md`
- 自动保存偏好：`docs/extension/global_preferences/04_自动保存与保存按钮偏好.md`
- 列表排序偏好：`docs/extension/global_preferences/components/13_列表排序偏好.md`
- 模块主文档：`docs/modules/04_notes.md`

## 3. 输出内容

- B 模块重构后的第一阶段 UI 结构定义
- 大体量笔记的结构分层方案
- 第二阶段待补项与阶段切换条件

## 4. 第一阶段目标

- 让 B 模块从“小笔记编辑器”升级为“适合几十万字私人笔记”的结构壳
- 先解决大体量内容下的定位、分块、阅读与切换入口问题
- 为后续“Markdown 自动转目录”“模块级显示”“目录复制”“关键词索引”预留稳定结构

## 5. 核心主功能

- 管理多条笔记
- 编辑单条 Markdown 笔记
- 从当前正文中抽取目录结构
- 基于目录标题形成模块筛选入口
- 保持自动保存优先，不引入保存式交互

## 6. 本阶段范围

- 要做：
  - 重构 B 模块页面布局
  - 引入“笔记列表 / 结构目录 / 正文编辑”三栏工作区
  - 从当前 Markdown 内容中前端抽取目录
  - 支持复制当前目录文本
  - 支持基于 H1/H2 的轻量模块筛选壳层
- 不做：
  - 不在第一阶段改动笔记底层存储格式
  - 不在第一阶段实现真正的块级数据库或关键词索引
  - 不在第一阶段完成“只显示某模块正文块”的真实内容折叠闭环
  - 不在第一阶段接入几十万字级别的全文检索

## 7. 第一阶段偏好应用范围

- 延续 B 模块自动保存优先的旧规则
- 不新增“保存笔记”“应用”“预览”按钮
- 保持说明条为低打扰说明，不做卡片套卡片
- 笔记列表继续支持拖拽排序
- 新增的目录/模块区域以扫描效率优先，不堆装饰性视觉

## 8. 页面入口

- 入口位置：顶部模式栏 `笔记`
- 进入方式：点击模式按钮切换
- 与旧入口关系：保留原入口，不新增独立模式

## 9. 页面结构

- 左栏：笔记列表
  - 新建笔记
  - 删除笔记
  - 笔记罗列与排序
- 中栏：结构目录区
  - 第一阶段说明条
  - 目录复制按钮
  - 模块筛选 chips
  - 目录列表
- 右栏：正文编辑区
  - 标题
  - Markdown 正文输入

## 10. 区块状态表

| 区块 | 当前状态 | 说明 | 下一阶段目标 |
|---|---|---|---|
| 笔记列表 | 已闭环 | 已有新建、删除、排序、切换能力 | 保持 |
| 结构目录 | 可触发未闭环 | 已能从当前 Markdown 抽标题与复制目录 | 接真实块级定位与目录跳转 |
| 模块筛选 | 可触发未闭环 | 已有模块 chips 壳层 | 接“只显示某模块正文块” |
| 正文编辑 | 已闭环 | 继续走自动保存链路 | 保持并增强大文档体验 |

## 11. 关键控件占位

- 按钮：
  - `新建笔记`
  - `删除笔记`
  - `复制目录`
- 输入：
  - `标题`
  - `内容（Markdown）`
- 状态区：
  - 结构摘要
  - 模块 chips
- 列表区：
  - 笔记列表
  - 目录列表

## 12. 面向大体量笔记的结构策略

- 只加载当前激活笔记正文，不在首屏同时展开多条笔记内容
- 用目录区承接定位需求，减少用户在长正文里反复滚动
- 第一阶段把 `H1/H2` 作为“模块级入口”的默认结构锚点
- 第二阶段若要做真正块级显示，优先沿用当前目录锚点，不另起一套完全不同的分块语法

## 13. 第二阶段待补项

1. 从 Markdown 真正解析出块结构与块内容映射
2. 模块筛选后只展示对应模块正文块
3. 目录项点击后让正文跳到对应块
4. 关键词抽取、关键词筛选、块级搜索
5. 面向几十万字内容的惰性解析与分段渲染

## 14. 阶段切换条件

### 允许进入第二阶段的条件

- 三栏结构稳定
- 目录区与模块区入口命名稳定
- 自动保存链路未被破坏
- 第一阶段文档已补齐

### 暂不进入第二阶段的情况

- 目录层级规则仍频繁改动
- 模块级定义还不明确
- 页面仍在“写一点改一点”的结构摇摆中

## 15. 第一阶段完成标准

- B 模块已从“双栏小编辑器”升级为“三栏重型笔记壳层”
- 用户能看见目录结构与模块筛选入口
- 目录可以复制
- 不新增保存式交互
- 第二阶段无需推翻整体布局
