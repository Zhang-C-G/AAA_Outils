# C模块第一阶段：笔记显示工作区重构

最近同步：`2026-05-07`
状态：`stage1`

- 本文档只负责 C 模块第一阶段：界面、结构、入口、占位、交互骨架与边界定义
- 本文档不负责第二阶段的完整悬浮窗联动增强、展示运行时同步细化、保护链路扩展闭环

## 3. 输出内容

- C 模块对标 B 模块后的第一阶段 UI 结构定义
- C 模块“目录区 + 正文工作区”的工作区重构方案
- 第二阶段待补项与阶段切换条件

## 4. 第一阶段目标

- 让 C 模块从“左侧输入 + 右侧预览”的旧结构，升级为对标 B 模块的“目录服务正文”工作区
- 让 C 模块的目录区、正文区、交互手感、聚焦反馈、视图切换方式，与 B 模块尽量同方向
- 为后续悬浮窗读取、目录联动、显示运行时同步预留稳定结构

## 5. 核心主功能

- 管理多条“笔记显示”内容
- 编辑单条 Markdown 内容
- 从当前正文中抽取目录结构
- 在同一块正文工作区中切换 `Markdown / 最终版本`
- 保持自动保存优先，不引入保存式交互

## 6. 本阶段范围

- 要做：
  - 重构 C 模块页面布局
  - 引入与 B 模块同方向的“列表 / 结构目录 / 正文工作区”结构
  - 将当前“正文预览”整合为正文工作区中的 `最终版本` 视图
  - 新增 `Markdown / 最终版本` 切换按钮
  - 让目录区继续服务当前正文工作区，而不是服务某个独立预览框
  - 对齐 B 模块的聚焦反馈、目录点击手感、左右列同构关系
- 不做：
  - 不在第一阶段改动 C 模块的悬浮窗保护主链路
  - 不在第一阶段把 C 与 B 合并为同一数据源
  - 不在第一阶段扩展复杂的悬浮窗运行时双向编辑
  - 不在第一阶段重写 AHK 侧悬浮显示框架

## 7. 第一阶段偏好应用范围

- 延续 C 模块自动保存优先的旧规则
- 不新增“保存内容”“应用”“预览”按钮
- 目录与正文工作区严格套用“笔记类目录与正文工作区偏好”
- 目录交互、点击反馈、滚动定位套用“结构目录偏好”
- `Markdown / 最终版本` 视图共用同一块正文工作区，不允许一大一小两套尺寸

## 8. 页面入口

- 入口位置：顶部模式栏 `笔记显示`
- 进入方式：点击模式按钮切换
- 与旧入口关系：保留原入口，不新增独立模式

## 9. 页面结构

- 左栏：笔记显示列表
  - 新建内容
  - 删除内容
  - 内容罗列与切换
- 中栏：结构目录区
  - 目录标题
  - 目录列表
  - 必要时保留轻量说明
- 右栏：正文工作区
  - 正文标题行
  - `Markdown / 最终版本` 视图切换
  - `Markdown` 文本框
  - `最终版本` 正文视图

## 10. 区块状态表

| 区块 | 当前状态 | 说明 | 下一阶段目标 |
|---|---|---|---|
| 内容列表 | 已闭环但结构偏旧 | 已有多条内容与切换能力 | 改成对标 B 的工作区入口 |
| 结构目录 | 可触发未收口 | 已能从 Markdown 生成目录 | 接正文工作区统一跳转体验 |
| 正文工作区 | 结构偏旧 | 仍是“编辑框 + 预览框”分离思路 | 改为 `Markdown / 最终版本` 同区切换 |
| 悬浮窗读取 | 已闭环 | 可从 `notes_display/*.md` 读取展示 | 保持，不在本阶段破坏 |

## 11. 关键控件占位

- 按钮：
  - `新建内容`
  - `删除内容`
  - `Markdown`
  - `最终版本`
- 输入：
  - `内容（Markdown）`
- 列表区：
  - 内容列表
  - 目录列表
- 正文区：
  - Markdown 输入视图
  - 最终版本阅读/编辑视图

## 12. 与 B 模块对标规则

- 目录区与正文区做成真正的左右同构列
- 目录区服务正文区，而不是只服务单独预览框
- 目录点击后，当前正文工作区立即定位到对应标题
- `Markdown / 最终版本` 使用与 B 模块同方向的切换结构
- 正文区点击与聚焦反馈保持低打扰，不接受原生白闪、突亮、抢焦点
- 不直接复用 B 的业务数据源，只复用结构、交互和工作区规则

## 13. 第二阶段待补项

1. C 模块正文工作区与悬浮窗展示态之间的同步策略细化
2. 目录定位与悬浮窗滚动定位的一致性增强
3. 更复杂的显示态只读/编辑边界控制
4. 运行时保护链路与正文工作区交互的异常说明
5. 展示态与编辑态的性能优化

## 14. 阶段切换条件

### 允许进入第二阶段的条件

- 三栏结构稳定
- `Markdown / 最终版本` 正文工作区结构稳定
- 目录与正文联动体验稳定
- 自动保存链路未被破坏
- 第一阶段文档已补齐

### 暂不进入第二阶段的情况

- 页面仍处于“旧结构和新结构混搭”的摇摆状态
- 目录跳转与正文视图切换还频繁变动
- C 模块是否保持独立数据源这件事还没写死

## 15. 第一阶段完成标准

- C 模块已从“左侧输入 + 右侧预览”升级为“列表 + 目录 + 正文工作区”
- 用户能在同一块正文工作区中切换 `Markdown / 最终版本`
- 目录能稳定服务当前正文工作区
- 不新增保存式交互
- 第二阶段无需推翻整体布局
