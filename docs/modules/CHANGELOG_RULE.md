# 模块修改过程文档规则

最近同步：`2026-04-26`
状态：`active`

## 1. 目标

从现在开始，每个模块都要维护自己的“修改过程记录文档”。

## 2. 强制规则

1. 每个主模块都必须有 1 份自己的修改过程文档
2. 该文档长期保留，不因 3 次改动 git checkpoint 而清空
3. 每次改动只要涉及某个模块，并且测试通过，就要同步追加到该模块文档
4. 如果一次改动同时影响多个模块，每个模块文档都要各自记录
5. 总流水文档 `docs/CHANGE_ACTIVITY_LOG.md` 继续记录“当前这一轮 1-3 次改动”
6. 模块修改过程文档负责记录“单模块的长期演进历史”

## 3. 当前要求覆盖的模块

- A 快捷字段
- B 笔记
- C 笔记显示
- D 截图发手机
- E 截图问答
- F 简历自动填写
- G 快捷键
- H 测试

## 4. 存放位置

统一放在：

- `docs/modules/changelog/`

## 5. 执行要求

以后凡是涉及模块改动，默认动作应变成：

1. 改代码 / 改文档
2. 测试通过
3. 更新该模块自己的修改过程文档
4. 更新总流水文档
5. 如达到 3 次改动阈值，再执行 git checkpoint
